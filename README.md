# 🍔 Tasty Burger

**Tasty Burger** is a food ordering website made using **React, TypeScript, and Vite**. Users can browse burgers, fries, and drinks, add items to their cart, manage quantities, and place orders.

## ✨ Features

- 🍔 Browse burgers, fries, and drinks
- 🛒 Add items to the shopping cart
- ➕ Increase or decrease item quantities
- ❤️ Add burgers to favorites
- 🔍 Search and filter menu items
- 📍 Sorsogon City, Bacon District location
- 🧾 Review cart items before checkout
- 🎨 Clean and responsive user interface

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- CSS
- JavaScript
- Lucide Icons

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/edmagineva3d/my_tasty-burger-app_V2.git
```

### 2. Open the Project Folder

```bash
cd my_tasty-burger-app_V2
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
