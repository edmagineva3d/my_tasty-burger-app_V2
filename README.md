# 🍔 Tasty Burger

A simple burger ordering web app made with **React, TypeScript, and Vite**.

## ✨ Features

- 🍔 View different burger products
- 🛒 Add burgers to the cart
- ➕➖ Change item quantity
- ❤️ Add items to favorites
- 💰 View prices and order total
- 📦 Checkout order
- 📱 Responsive design




## 🛠️ Technologies

- ⚛️ React
- 📘 TypeScript
- ⚡ Vite
- 🎨 CSS
- 🛒 React Context

## 🚀 How to Run

Open the project in VS Code, then run:

```bash
npm install
npm run dev
```

Open the local link shown in the terminal.

## 📁 Main Folders

```text
src/
├── components/  # reusable components
├── pages/       # app pages
├── context/     # cart state
├── assets/      # images
└── App.tsx      # main app
```

## 👨‍💻 Project

Made as a student web app project. 🍔✨

**Tasty Burger — Fresh burgers, easy ordering!** 🍟🥤
=======
## 📖 About

**Tasty Burger** is a food ordering website made using **React, TypeScript, and Vite**. Users can view burgers, fries, and drinks, add items to the cart, and place an order.


## ✨ Features

* View the menu
* Add items to cart
* Increase or decrease quantity
* Remove items from cart
* View total price
* Favorite items
* Customer reviews
* Login and Register modal
* Responsive design
