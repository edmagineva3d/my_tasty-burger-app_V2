<h1 align="center">🍔 Tasty Burger V2</h1>

<p align="center">
  <strong>Tasty Burger</strong> is a food ordering website made using <strong>React, TypeScript, and Vite</strong>. Users can browse burgers, fries, and drinks, customize their orders, add items to their cart and favorites, apply discounts, and complete checkout with different payment options.
</p>

## ✨ Features

- 🍔 Browse burgers, fries, and other menu items
- 🔍 Search and filter menu items
- ❤️ Add and manage favorite items
- 🛠️ Customize burgers with different add-ons and ingredients
- 🍟 Choose fries sizes, toppings, and preparation options
- 🛒 Add items to cart and manage quantities
- 💰 View prices, discounts, and order totals
- 🎟️ Apply discount and promo codes
- 🍱 Explore recommended meals and smart bundles
- 📝 Enter customer information and delivery instructions
- 💳 Choose Cash on Delivery (COD) or GCash
- 📦 Complete checkout and view order confirmation
- 🚚 Track orders through a step-by-step status timeline
- 🧾 View order history saved in the browser
- 🚫 Display sold-out labels for unavailable items
- ⭐ Customer reviews
- 🔐 Login and Register modal
- 📱 Responsive design with interactive animations

## 🚀 How to Run

1. Clone the repository:

   ```powershell
   git clone https://github.com/edmagineva3d/my_tasty-burger-app_V2.git
   ```

2. Open the project folder in VS Code:

   ```powershell
   cd my_tasty-burger-app_V2
   ```

3. Install the project dependencies:

   ```powershell
   npm.cmd install
   ```

4. Start the development server:

   ```powershell
   npm.cmd run dev
   ```

5. Open the local URL displayed in the terminal, usually `http://localhost:5173`.
