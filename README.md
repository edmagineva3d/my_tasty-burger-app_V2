<h1 align="center">🍔 Tasty Burger V2</h1>

<p align="center">
  <strong>Tasty Burger</strong> is a food ordering website made using <strong>React, TypeScript, and Vite</strong>. Users can browse burgers, fries, and drinks, add items to their cart, manage quantities, and place orders.
</p>

## ✨ Features

- 🍔 Browse burgers, fries, and drinks
- 🛒 Add items to cart
- ➕➖ Increase or decrease item quantity
- ❌ Remove items from cart
- ❤️ Add items to favorites
- 💰 View prices and order total
- 📦 Checkout orders
- 🚫 Sold-out labels that prevent unavailable items from being added to cart
- 🚚 Order tracking with a step-by-step status timeline
- 🧾 Order history saved in the browser
- ⭐ Customer reviews
- 🔐 Login and Register modal
- 📱 Responsive design
